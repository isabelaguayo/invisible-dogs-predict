# Resultados

Esta carpeta reúne resultados derivados del desarrollo experimental del TFM que sea útil conservar de forma independiente a los notebooks.

Contenido previsto:

```text
outputs/
├── metrics/              # Métricas, comparativas y validaciones
├── interpretability/     # Resultados de interpretabilidad
├── regression/           # Resultados del análisis de regresión
├── petfinder/            # Resultados complementarios PetFinder
├── petfinder_visual/     # Resultados visuales PetFinder
├── tsinghua_visual/      # Validación externa y recuperación visual
└── testing/              # Resultados de validación e integración
```

Se priorizarán CSV, JSON y otros ficheros pequeños o medianos que aporten trazabilidad científica. Los artefactos pesados que sean necesarios para ejecución se ubicarán en `artifacts/`.
