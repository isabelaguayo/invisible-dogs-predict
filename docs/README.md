# Documentación complementaria

Esta carpeta reúne documentación de apoyo de **InvisibleDogs Predict** orientada a facilitar la revisión técnica, la trazabilidad y la reproducibilidad del proyecto.

## Objetivo

La documentación de esta carpeta complementa al `README.md` principal, a los notebooks y a la documentación específica del frontend. Su finalidad es describir aspectos transversales del sistema que no necesitan formar parte del código ni de los notebooks experimentales.

## Contenido

La documentación complementaria puede incluir:

- arquitectura del sistema;
- relación entre notebooks, modelos, resultados y aplicación;
- criterios de reproducibilidad;
- decisiones técnicas relevantes;
- descripción de servicios y publicación;
- documentación adicional útil para la evaluación y mantenimiento del proyecto.

## Documentación relacionada

- `../README.md`: visión global del proyecto.
- `../notebooks/README.md`: secuencia metodológica de los notebooks.
- `../data/README.md`: fuentes y organización de datos.
- `../artifacts/README.md`: modelos, embeddings e índices.
- `../outputs/README.md`: resultados y evidencias experimentales.
- `../frontend/README.md`: aplicación web.
- `../frontend/DATA-INTEGRATION.md`: trazabilidad entre datos científicos y web.

La memoria académica completa se mantiene separada del código salvo que forme parte explícita de la entrega final del repositorio.
